# Scope, ethics and evidence labels

**Author:** Hansal Savaliya, Intern ID 2424 (RedKross Research Foundation, Milestone Task 3: Malware Research)

## Scope

This repository is **defensive research**. It documents how four classes of AI-assisted botnet work, how to detect them and how to reduce the risk. It contains:

- written analysis (architecture, execution flow, attack vectors, kill chains),
- indicators of compromise (IoCs) taken from published reports,
- YARA and Sigma detection rules, tested on harmless synthetic text,
- small analysis scripts that run **only on synthetic data** I generated.

## What this repository does not contain

- No functional malware, exploit code, botnet controller, spam tool, miner configuration or CAPTCHA/anti-bot bypass.
- No malware samples, and no real credentials, API keys, wallets or personal data.
- No scanning or testing of any system I do not own. All work is offline reading plus local scripts on synthetic data.

## Evidence labels used throughout

| Label | Meaning |
|-------|---------|
| **[EVIDENCED]** | Described in a published report from a named researcher or vendor (cited in `references.md`). |
| **[INFERRED]** | The researchers' own inference or my reasoning from evidence. The text says whose. |
| **[CONCEPTUAL]** | A hypothetical variant. No public evidence found that it exists. Used to reason about defences. |

Where the four assigned topics have no public evidence for the exact system (notably Topics 3 and 4), I say so and build the analysis from evidenced components, clearly labelled.

## Synthetic data provenance

All data in `data/` was generated by `scripts/make_synthetic_data.py` with a fixed random seed. It contains invented reviews, invented telemetry and invented log lines. None of it comes from a real person, company or system.
